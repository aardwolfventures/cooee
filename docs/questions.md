# The questions v1 must answer

This list is the actual deliverable. The app is only the instrument.

Fill this in during and immediately after each session — not from memory the
next day. Two rounds, a week apart, with changes in between.

## How to run a session

Send the URL to four mates. Do not explain anything.

Run each scenario for a few minutes on the simulated clock while everyone has
it open. Watch what they do and say. Say as little as possible: the instinct to
explain the interface is the instinct to resist, because in the field nobody
will be there to explain it.

Afterwards ask exactly one open question — **what would you change** — and then
shut up.

## Verdict

Continue if people correctly distrust stale data without being told to, the
presets mostly cover what they want to say, and at least one person asks when
they can use it for real.

Stop or rethink if people treat every dot as current, the map is not glanceable
at arm's length in sunlight, or the consistent feedback is that they would
rather just use the radio.
